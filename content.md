## Brand System (read this first — referenced by every image prompt)

**Every image must follow these rules. Copy the "Artemis Brand Block" into every prompt.**

### The Artemis Brand Block (paste into every image prompt)

```
BRAND: Artemis — analytics platform for PH COD e-commerce.
PALETTE: Primary green #10D3A1 (emerald/teal), deep green #0A9C7A for gradients.
         Background: either near-black zinc-950 (#0A0A0B) OR pure white.
         Accent grays only (#6B7280, #9CA3AF). No other colors.
LIGHTING: On dark backgrounds, add a soft radial green glow behind focal elements
          (rgba(16,211,161,0.12), ellipse, 900x500px, centered/off-center).
TEXTURE: Subtle 60x60px grid overlay on background (1px lines, 3% opacity on white /
         1.5% opacity on dark). Not dominant — atmospheric.
TYPOGRAPHY: Modern sans-serif (Inter / Geist). Headlines bold, tight tracking.
            Uppercase mono small-caps for meta labels (letter-spacing 0.2em).
            Key emphasis words in italic emerald green.
MOTIFS: Hunter/archer themes — crosshairs, target reticles, directional arrows,
        tracking lines, radar sweeps. Artemis = Greek goddess of the hunt.
        Data visualization: clean line charts, downward-trending RTS curves,
        map pins on PH geography.
VOICE ON IMAGE: Direct, numeric, confident. No stock-photo smiling people.
                When humans appear: operators at laptops, warehouse scenes,
                Filipino settings — authentic, not posed.
FORBIDDEN: Gradients outside green family. Rainbow UI. Cartoon mascots.
           Generic startup handshakes. Emoji-heavy compositions. Western-only
           imagery (this is a PH product — show PH context).
ASPECT: {SPECIFY PER POST — 1:1 for IG feed, 9:16 for TikTok/Reels, 1.91:1 for FB link}
STYLE: Tech editorial meets hunter/tracker field-guide. Minimal, sharp,
       operator-grade. Think Linear.app meets a ballistic targeting UI.
```

## Brand Enforcement Checklist (run before publishing ANY image)

- [ ] Primary color is Artemis emerald `#10D3A1` (not generic green)
- [ ] Background is zinc-950 dark OR pure white — nothing in between
- [ ] No non-green accent colors (zero blue, zero orange, zero rainbow)
- [ ] Emphasis words in italic emerald gradient
- [ ] Mono uppercase meta labels with `0.2em` letter-spacing
- [ ] Subtle grid overlay present (but not dominant)
- [ ] Radial emerald glow on dark compositions
- [ ] Artemis wordmark OR logo visible (except native group posts)
- [ ] PH context visible when humans/scenes are shown
- [ ] Hunter/target motif where appropriate (crosshair, arrow, reticle, radar)
- [ ] Zero stock-photo smiling handshakes
- [ ] Voice is direct, numeric, operator-to-operator
